!!! info "URLs in deze handleiding"
    De URLs hieronder gebruiken het **k3d-laptop-domein** (`*.uwv-platform.local:8443`).
    Op andere modes:

    - **aks** (Azure): vervang `*.uwv-platform.local:8443` door `*.eu-sovereigndataplatform.com` (poort 443, dus geen `:8443`).
    - **stackit** (SKE): vervang door `*.freshstackable.com` (poort 443).

    Zie [Deployment modes](../deployment-modes.md) voor de complete matrix.
